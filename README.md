## 👋 About me

I'm **Obiajulu Chisom**, a JavaScript and TypeScript developer who builds web apps end to end: React and Next.js interfaces on top of Node.js, Supabase and PostgreSQL. I like readable backends and interfaces that stay out of the way.

|     |     |
| --- | --- |
| 🌍 **Based in** | Togo |
| 🧠 **Focus** | Web apps with TypeScript, Next.js and Supabase |
| 🔭 **Working on** | [caZTube](https://github.com/chisom-1010/caztube), a video platform with a new FastAPI backend |
| 🌱 **Learning** | Python, FastAPI, C# and .NET |
| 💼 **Open to** | Junior roles, internships and web development gigs |
| ⚡ **Also** | Big weeb 👀 |
